Zaid Speedcube Timer icon pack

Copy the contents of:
android/app/src/main/res/
into the same path in your speedcuber-timer fork, overwriting existing launcher icon files.

This package contains:
- Legacy launcher icons: mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi
- Adaptive icon XML for Android 8+
- Transparent adaptive foreground derived from the uploaded logo
- White adaptive background
